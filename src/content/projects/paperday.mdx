## Overview

**Paperday** is a lightweight, browser-native calendar maker designed to produce clean, high-precision printable calendars without requiring any heavy PDF engines, third-party backend servers, or framework runtimes.

Everything runs purely on standard web platform APIs—HTML, Vanilla JavaScript (ES modules), and dedicated print stylesheets.

## Key Features

- **Multiple Layout Modes:** Monthly overview, compact multi-month grids, and full 12-month single-sheet yearly posters.
- **Print-First Precision:** CSS `@media print` rules calibrated specifically for standard A4 and US Letter dimensions with crisp lines and zero page overflow.
- **Zero Build / Zero Dependencies:** Pure ES modules and web standards that load instantly and work offline.
